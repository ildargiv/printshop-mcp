**Типография внутри вашего ИИ-агента.** Попросите: «бейджи для этих 40 гостей, визитки и флаер». Агент сверстает
их, разложит на листы, покажет точный пробный оттиск и напечатает на **вашем принтере** с точностью до миллиметра.
И **запомнит все ваши профили печати**: принтер, бумагу, лоток, тип носителя, качество, цветовой профиль, калибровку
и даже фирменные настройки драйвера. Один раз объяснили — больше никогда.

> Статус: v0.2, Windows. Новое: печать любых PDF (например, из других дизайн-скилов) и автоматическая раскладка множества изделий (`layout`). Дальше: самообучение на ошибках печати, macOS/Linux.

## Совместимость с принтерами

**Для бумажных принтеров: струйных, лазерных, фотопринтеров, сублимационных и принтеров этикеток. Не для 3D-принтеров.**

Работает с любым принтером, у которого есть драйвер Windows, независимо от бренда: печать идёт через стандартную систему печати Windows, а фирменные настройки (тип бумаги, печать без полей, качество) сохраняются в профилях через родное окно драйвера.

| Тип принтера | Бренды |
|---|---|
| Струйные | Epson · Canon · HP · Brother |
| Лазерные и МФУ | HP · Brother · Canon · Kyocera · Xerox · Ricoh · Konica Minolta · Sharp · Lexmark · OKI · Pantum · Samsung |
| Фотопринтеры (струйные) | Epson · Canon · HP |
| Сублимационные (фото) | DNP · Mitsubishi · Citizen · HiTi · Kodak · Canon Selphy |
| Этикеток / термо | Zebra · TSC · Brother QL · Dymo · Xprinter |

| Принтер | Тип | Статус |

## Установка

**Claude Code** (скил и MCP-сервер одним плагином):

```
/plugin marketplace add ildargiv/printshop-mcp
/plugin install printshop@printshop-mcp
```

**Любой MCP-клиент** (Claude Desktop, Cursor, Codex…):

```json
{ "mcpServers": { "printshop": { "command": "uvx",
    "args": ["--from", "git+https://github.com/ildargiv/printshop-mcp", "printshop-mcp"] } } }
```

Нужны [uv](https://docs.astral.sh/uv/) и Edge или Chrome (для рендера).

## Чем лучше Ctrl+P

| Ctrl+P | printshop-mcp |
|---|---|
| «Вписать в страницу» тихо масштабирует: 90 мм превращаются в 88,7 | Рендер сразу в пиксели принтера: 1 мм в CSS = 1 мм на бумаге |
| Содержимое попадает в непечатное поле | Оттиск показывает реальную непечатную зону, проверка предупреждает |
| Агент не видит результат | Картинки оттиска и отчёт: обрезанный текст, мелкие фото, не та бумага |
| Настройки каждый раз забываются | Именованные профили с полным состоянием драйвера, калибровкой и ICC |
| Один вид изделий за печать | Бейджи, визитки и флаеры на общих листах с метками реза |

## Что получает агент

- **Скил** `skills/printshop`: порядок работы (профили → макет → оттиск → печать → правка профиля), правила HTML,
  справочник раскладок и шаблоны: бейджи 90×55, визитки 90×50, флаеры A6, табличка-домик, смешанный лист.
- **Команды MCP**: `list_printers`, `describe_printer`, `list_profiles`, `save_profile` (`open_driver_dialog=true` —
  настроить фирменные опции один раз в окне драйвера), `layout`, `proof`, `print_job`, `printer_status`.
- **HTML**: каждый лист — `<section class="ps-sheet" style="width:210mm;height:297mm">`, вёрстка в мм;
  `data-fit="9pt"` уменьшает текст, чтобы влез; `data-cut` ставит метки реза.

## Безопасность

Печать только после оттиска; задание живёт 1 час и печатается один раз. `PRINTSHOP_MAX_SHEETS` (по умолчанию 50)
ограничивает расход бумаги, `PRINTSHOP_DRYRUN=1` полностью отключает печать.
