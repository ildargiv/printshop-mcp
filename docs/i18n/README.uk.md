**Друкарня всередині вашого ШІ-агента.** Попросіть: «бейджі для цих 40 гостей, візитки й флаєр». Агент зверстає їх,
розкладе на аркуші, покаже точний пробний відбиток і надрукує на **вашому справжньому принтері** з точністю до
міліметра. І **запам’ятає всі ваші профілі друку**: принтер, папір, лоток, тип носія, якість, колірний профіль,
калібрування і навіть фірмові налаштування драйвера. Пояснили один раз — і досить.

> Статус: v0.2, Windows. Нове: друк будь-яких PDF (наприклад, з інших дизайн-скілів) і автоматичне розкладання багатьох виробів (`layout`). Далі: самонавчання на помилках друку, macOS/Linux.

## Сумісність із принтерами

**Для паперових принтерів: струменевих, лазерних, фотопринтерів, сублімаційних і принтерів етикеток. Не для 3D-принтерів.**

Працює з будь-яким принтером, для якого є драйвер Windows, незалежно від бренду: друк іде через стандартну систему друку Windows, а фірмові налаштування (тип паперу, друк без полів, якість) зберігаються в профілях через рідне вікно драйвера.

|---|---|
| Струменеві | Epson · Canon · HP · Brother |
| Лазерні та БФП | HP · Brother · Canon · Kyocera · Xerox · Ricoh · Konica Minolta · Sharp · Lexmark · OKI · Pantum · Samsung |
| Фотопринтери (струменеві) | Epson · Canon · HP |
| Сублімаційні (фото) | DNP · Mitsubishi · Citizen · HiTi · Kodak · Canon Selphy |

## Встановлення

**Claude Code** (скіл і MCP-сервер одним плагіном):

```
/plugin marketplace add ildargiv/printshop-mcp
/plugin install printshop@printshop-mcp
```

**Будь-який MCP-клієнт** (Claude Desktop, Cursor, Codex…):

```json
{ "mcpServers": { "printshop": { "command": "uvx",
    "args": ["--from", "git+https://github.com/ildargiv/printshop-mcp", "printshop-mcp"] } } }
```

Потрібні [uv](https://docs.astral.sh/uv/) та Edge або Chrome (для рендерингу).

## Чому не Ctrl+P

| Ctrl+P | printshop-mcp |
|---|---|
| «Вмістити на сторінку» непомітно масштабує: 90 мм стають 88,7 | Рендер одразу в пікселі принтера: 1 мм у CSS = 1 мм на папері |
| Вміст потрапляє в недрукований край | Відбиток показує справжню недруковану зону, перевірка попереджає |
| Агент не бачить результату | Зображення відбитка та звіт: обрізаний текст, дрібні фото, не той папір |
| Налаштування щоразу забуваються | Іменовані профілі з повним станом драйвера, калібруванням та ICC |
| Один вид виробів за друк | Бейджі, візитки й флаєри на спільних аркушах із мітками різу |

## Що отримує агент

- **Скіл** `skills/printshop`: порядок роботи (профілі → макет → відбиток → друк → виправлення профілю), правила HTML,
  довідник розкладок і шаблони: бейджі 90×55, візитки 90×50, флаєри A6, табличка-будиночок, змішаний аркуш.
- **Команди MCP**: `list_printers`, `describe_printer`, `list_profiles`, `save_profile` (`open_driver_dialog=true` —
  один раз задати фірмові опції у вікні драйвера), `layout`, `proof`, `print_job`, `printer_status`.
- **HTML**: кожен аркуш — `<section class="ps-sheet" style="width:210mm;height:297mm">`, верстка в мм;
  `data-fit="9pt"` зменшує текст, доки він не вміститься; `data-cut` ставить мітки різу.

## Безпека

Друк лише після `proof`; завдання діє 1 годину і друкується один раз. `PRINTSHOP_MAX_SHEETS` (типово 50)
обмежує витрату паперу, `PRINTSHOP_DRYRUN=1` повністю вимикає друк.
